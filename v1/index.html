05 / OFF THE PAGE

How I approach the work

The part a résumé
doesn’t capture.

  1. 01

    Trace the whole path.

    A feature isn’t only its happy-path handler. Follow the request through auth, state, queues, logs, and failure.

  2. 02

    Make failure legible.

    Retries and fallbacks matter. So does making it obvious what happened when they finally stop working.

  3. 03

    Learn one layer lower.

    Build the scheduler. Build the database. Understanding the layer below makes decisions at the current layer sharper.
